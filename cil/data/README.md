# CIL 학습 데이터

학습 샘플 하나는 **카메라 이미지, 현재 속도, 진행 명령, 조향·가속·제동 정답**으로 구성된다. 정답은 기준 경로를 따라가는 Pure Pursuit 제어기에서 얻었다. [수집 세션과 검사 결과](collection_summary.csv)

## 수집에서 학습 입력까지

1. [collect.py](../collect.py)는 세 카메라의 이미지, 차량 상태, 진행 명령과 시범 제어값을 저장한다. 조향 교란을 넣은 주행에서는 실제로 보낸 제어값과 차량이 경로로 복귀하도록 계산한 정답을 각각 기록한다.
2. [prepare.py](../prepare.py)는 품질 검사를 통과한 주행을 읽고, 이미지의 센서 시각과 속도·제어 정답을 맞춘다. 좌우 카메라 영상에는 카메라 위치와 방향을 반영한 복귀 조향을 붙인다. 학습과 검증은 도로 단위로 분리한다.
3. [dataset.py](../dataset.py)는 각 이미지를 RGB 200×88로 전처리하고 학습용 이미지에 증강을 적용한다. 세 카메라 영상은 한 번에 묶지 않고 각각 한 샘플로 사용한다.

## 파일

| 파일 | 내용 |
|---|---|
| `data/raw/<세션>/images.csv` | 이미지 경로, 카메라, 센서 시각 |
| `data/raw/<세션>/vehicle.csv` | 차량 속도·위치 등 차량 상태 |
| `data/raw/<세션>/commands.csv` | 진행 명령, 정답 제어, 실제 전송값 |
| `data/prepared/train.csv`, `val.csv` | 학습·검증용 입력과 정답을 연결한 목록 |

원본 이미지와 프레임별 목록은 로컬에 보관했다. 준비 CSV는 원본 파일을 복사하지 않고 이미지 경로를 참조한다. 진행 명령 코드는 [설정 파일](../config.json)에 있으며, 조향 정답은 `-1~1`, 가속·제동은 `0~1`로 정규화한다.
