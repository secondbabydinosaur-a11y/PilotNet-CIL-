# CIL이 사용한 경로

MORAI K-City의 도로를 학습·검증·시험 용도로 나눴다. 학습할 때는 경로를 따라가는 시범 제어기로 데이터를 만들고, 주행할 때는 경로에서 도로 추종·좌회전·직진·우회전 명령을 정한다.

| 경로 | 용도 |
|---|---|
| [`train/`](train/) | 일반 도로 시범과, 같은 교차로 접근로에서 출구를 달리한 세 가지 주행 |
| [`val/`](val/) | 학습과 다른 도로에서 모델 선택에 사용 |
| [`test/`](test/) | 학습·검증에 쓰지 않은 곡선과 교차로 시험, 대회 경로 시연 |

## 시험 경로 이름

- `U2`는 곡선에서 직선으로 이어지는 약 232 m 구간이다. [곡선 경로](test/U2.csv)
- `J`는 K-City 기준 경로 초반의 시험 교차로다. 같은 출발점에서 각각 [직진](test/J_straight.csv), [좌회전](test/J_left.csv), [우회전](test/J_right.csv)했다. [교차로 위치와 출구 그림](../results/README.md#시험-교차로)
- `COMPETITION`은 대회 출발점에서 마지막 좌회전 출구 뒤까지의 연속 주행 경로다. 학습 도로 인근을 지나며, 짧은 시험 구간과 별도로 시연했다. [시연 영상](../results/README.md#point-to-point-주행)

경로 파일과 출발 조건은 [수집 계획](plan.json)과 [시험 목록](test/manifest.json)에 있다. 실제 시범 수집에 사용한 경로는 [수집 기록](../data/collection_summary.csv)에서 확인할 수 있다.
