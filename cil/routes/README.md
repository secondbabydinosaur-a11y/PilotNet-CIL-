# CIL 수집·시험·시연 경로

`train/`과 `val/`은 물리적인 도로 구역에 따라 나눴다.
`test/`에는 미학습 도로 시험 경로와 학습 도로를 포함하는 대회 연속 시연 경로를 용도별로 구분해 보관한다.
지도에서 경로와 명령을 정하고 실제 MORAI Teacher 수집으로 확인한다.
수집 완료·품질 통과 여부는 [실제 수집 기록](../data/collection_completion.json)에 보관한다.
선정에 사용한 지도 파일의 SHA256, 기존 시험 구역과의 분리 검사 및 경로별 출발·종료 좌표는
[plan.json](plan.json)에 기록했다.

CSV 열은 `s_m,x_m,y_m,z_m`이다.
`s_m`은 각 경로의 시작부터 누적한 거리다. `COMPETITION_REVERSE`의 0~608.085m는 돌아오는 경로의 진행거리이며 원래 대회 진행거리와 구분한다.
XYZ는 MGeo 월드 좌표(m)다. X는 동쪽, Y는 북쪽이며 UTM 52N 원점은 `[302595, 4124145, 0]`이다.
센서 장착 위치를 나타내는 차량 기준 XYZ와 구분한다.
`plan.json`의 `route_csv`는 `cil/` 기준 상대경로다.

U1·U2와 교차로 J의 세 출구는 `plan.json`의 `test_reservations`에 시험 구역으로 보존했다.
이 예약 구역의 경계·여유 점열을 그대로 시험용 주행 경로로 사용하지 않는다.
U2·J 세 방향·대회 연속 시연의 실제 실행 경로와 명령 구간·출발 좌표는 [시험·시연 목록](test/manifest.json)에 기록했다.
학습의 `CENTRAL_*`는 J와 떨어진 별도 교차로다. 동일한 접근 영상에 서로 다른 명령을 부여한다.
T5 CSV는 초기 후보를 보존한 파일이며, 실제 용도는 `plan.json`의 `split=calibration`이다.

`COMPETITION_REVERSE` 시연은 마지막 좌회전 신호 `C1256W000052`의 정지선(원래 대회 s609.601m) 약 **4.6m 전**에 대응하는 반대 차로에서 출발한다.
출발 위치는 원래 s605.017m 부근, 종점은 원래 s0.038m 부근이며 원래 출발점에서 약 **5.02m 옆의 반대 차로**다.
원본 좌표를 뒤집어 역주행하는 방식이 아니라 **MGeo 정상 진행 방향의 반대 차로 링크 21개**를 연결했다.
총길이는 **608.084522m**이며 원래 마지막 좌회전 링크에는 진입하지 않는다.
교차로 명령은 **좌회전 → 직진 4회 → 우회전** 순서다. 교차로 사이에는 도로 추종 명령을 사용한다.

이 경로는 실제 학습 주행 위치와 3.5m 이내로 가까운 구간이 약 **53.04%**이며, 준비된 학습 샘플 위치 기준으로는 약 **52.96%**다.
같은 도로 배경을 반대 시점에서 보는 주행이므로, 진행 방향이 다르다는 이유로 미학습 도로 일반화 시험으로 취급하지 않는다.
지도는 초기 배치·진행 명령·평가에만 사용하며 조향·가속·브레이크는 고정된 CIL Baseline 19 epoch 모델이 예측한다.
신호색·장애물 대응은 학습·평가 범위 밖이며, 7m 관찰 기준의 종점 도달은 차선 정밀 주행·무충돌·규정 준수를 보장하지 않는다.

이전 [대회 출발→마지막 좌회전 경로](test/COMPETITION.csv)의 645.113m CSV는 과거 시연 재현용으로 보존한다.
현재 공개 point-to-point 비교 영상의 대상은 `EAST_OUTER_EXTENDED`다. [주행 영상과 구간별 결과](../results/README.md#point-to-point-주행)
과거 [P→Q CSV](test/P2Q.csv)는 고정된 수집 분할과 준비 과정을 재현하기 위해 남겼다.
현재 평가 목록·공개 영상·결과 표에는 포함하지 않는다. 현재 연속 시연 결과는 [대표 영상](../results/README.md)에 있다.

그림과 경로는 [CIL 안내](../README.md)에서 함께 볼 수 있다.
